# 参数、接口与数据口径

## 2026-11-16布局与临时分享参数

- Cookie `layout_mode`：仅允许 `mobile` / `desktop`，有效期1年；不合法值忽略，首次按760px屏宽选择。纯展示偏好，不参与权限和统计。
- 布局容器：手机版最大430px、PC版最小1100px；模块使用容器查询保持一致切换。PC版在窄屏上允许横向浏览。
- `/health` 版本为2026.11.16.2，`profile`支持personal/demo/public。
- `public_share.py [--no-browser]`：独立公网账本目录data/public、端口8003、HOST=127.0.0.1、COOKIE_SECURE=1；SSH只转发该端口，不转发正式8000和演示8001。
- `data/public/public-url.txt`记录当前通道地址；`tunnel.log`和`known_hosts`保存本机通道状态。公开链接依赖本机在线，地址可能轮换；此模式未提供常驻云服务SLA。
- 保活器：`public_share.py --keep-alive`，每30秒进行一次真实HTTPS健康检查；连续运行时检测无效链接后重连，错误写入`data/public/monitor.log`。本机127.0.0.1:8004独占绑定防止重复保活器，此端口不对外提供服务。新地址只在HTTPS健康检查通过后保存；不保证第三方通道永久不变。

本文是配置和业务参数的唯一集中说明。应用使用 HTML 表单与服务端模板，不暴露通用 JSON API。默认时区为北京时间 UTC+8，金额均为人民币。

## 1. 运行配置（环境变量）

2026-11-16新增 `launcher.py`：`--mode personal|demo`（默认personal）选择独立账本，`--no-browser`用于只启动检查。CMD入口使用启动器，自动绑定0.0.0.0以便同一局域网手机访问；个人端口8000、演示8001。`/health`返回应用标识、版本、模式，不返回用户数据。相同版本服务复用；旧版本或其他服务占用端口时提示关闭原窗口。后台日志位于对应DATA_DIR/server.log。原run.py仍支持环境变量和前台运行。

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `HOST` | `127.0.0.1` | 监听地址；局域网可设 `0.0.0.0`，不是用户访问网址 |
| `PORT` | `8000` | 监听端口，演示脚本使用8001 |
| `OPEN_BROWSER` | `0` | 设为1时，绑定端口成功后自动打开本机浏览器；CMD启动入口启用 |
| `DATA_DIR` | 项目下 `data` | 持久化目录；数据库 `ledger.sqlite3`、密钥 `secret.key`；推荐绝对路径 |
| `SECRET_KEY` | 首次自动生成并存入密钥文件 | 会话签名密钥；更换后所有会话失效；多实例须统一 |
| `COOKIE_SECURE` | `0` | HTTPS 部署须为 `1`；本地 HTTP 使用 `0` |

应用内部固定配置：上传总请求最大5 MiB；会话最多7天；CSRF令牌随会话；登录失败按 IP+账号15分钟内最多10次。文件和导入预览有明文财务数据，不应公开 data 目录。SQLite 本身不提供磁盘加密。

## 2. 公共表单字段

所有 POST 请求都必须携带 `csrf`，由模板隐藏字段自动提交。所有业务页面需要登录。无权限返回403/404，参数错误400，文件过大413，登录尝试过多429。登录有效后采用浏览器 Cookie 会话。

| 字段 | 格式 / 取值 | 说明 |
| --- | --- | --- |
| `month` | `YYYY-MM` | 查询月份，默认当前月；预算表单同样使用 |
| `scope` | `all`、`me`、`others` | 全部、本人、家人。首页/统计的all仅含家庭共享记录；账单明细/导出的all为本人全部+家人共享 |
| `q` | 最多100字 | 明细商家、备注的不区分大小写包含匹配 |
| `category` | 分类名 | 明细精确过滤；预算保存时可选“总预算” |

## 3. 账号与家庭

| 路径 / 方法 | 参数 | 作用 |
| --- | --- | --- |
| `/register` GET/POST | `username` 3～32位ASCII字母数字下划线；`name` 1～20字；`password` 10～128位 | 注册独立账号，同时建立个人家庭；账号不区分大小写 |
| `/login` GET/POST | `username`、`password` | 登录，密码使用 PBKDF2-SHA256 600000轮加盐哈希 |
| `/logout` POST | 无 | 清除会话 |
| `/family` GET/POST | 无 | 查看成员；管理员POST生成24小时、一次性邀请码 |
| `/join` GET/POST | `token` 邀请码 | GET预览，POST明确确认；切换家庭时所有个人账单取消共享 |
| `/family/leave` POST | 无 | 保留个人账单，取消共享，建立新个人家庭；有其他成员时管理员不能退出 |

家庭权限：每个用户只有一个当前家庭。管理员可邀请和管理预算，不能编辑他人账单；成员可读取他人显式共享的账单。退出后旧家庭不再能看到该用户账单，旧家庭统计随之变化。当前不支持仅共享汇总、分类自动共享、管理员强制移除、所有权转让或多家庭。邀请链接可将 `/join?token=邀请码` 拼到实际访问域名后，或直接粘贴邀请码。

## 4. 单笔账单参数

路径：`/entry/new` GET/POST；`/entry/<id>` GET/POST。

| 字段 | 约束 | 说明 |
| --- | --- | --- |
| `kind` | `expense` / `income` / `transfer` / `refund` | 支出/收入/转账/退款 |
| `amount` | 大于0且小于十亿元，最多两位小数 | 内部存整数分；拒绝科学计数法、负数、NaN |
| `merchant` | 1～120字 | 名称或交易对方 |
| `category` | 内置/用户自定义分类 | 默认餐饮、居家、购物、交通、娱乐、医疗、教育、工资、其他、待确认 |
| `occurred` | `YYYY-MM-DDTHH:MM` | 北京时间，不含时区偏移 |
| `channel` | 1～40字 | 账户/支付渠道，可手填；此版本不维护账户余额 |
| `note` | 最多300字 | 可选；超过部分截断 |
| `shared` | 勾选值 `1` | 未勾选为私有；已共享账单取消勾选即可撤回共享 |
| `nonce` | 系统生成 | 新增表单防重复提交，保留最近10个表单，保存后失效 |

`/entry/<id>/delete` POST 软删除，`/entry/<id>/restore` POST 恢复；均限本人。回收站界面展示最近30条。移除自定义分类保留历史分类，编辑旧记录时可继续保留原分类。

## 5. 导入参数和适配范围

`/import` POST：`file` CSV/XLSX、`channel` 微信/支付宝/其他。未解压ZIP、加密XLSX、PDF、旧XLS不支持。最多11000行、Excel解压后最多30 MiB；只读取首张工作表和前40列。CSV 支持UTF-8 BOM/UTF-8/GB18030以及逗号或制表符分隔；前100行查找表头。

支持常见微信/支付宝导出列的别名（并非承诺兼容所有历史/未来版本）：

| 标准字段 | 可接受表头 |
| --- | --- |
| 时间（必需） | 交易时间、交易创建时间、创建时间、时间、日期 |
| 金额（必需） | 金额(元)、金额（元）、金额、交易金额 |
| 收支（必需） | 收/支、收支、收支类型、类型 |
| 商家 | 交易对方、对方、商家、名称 |
| 备注 | 商品、商品名称、商品说明、备注 |
| 状态 | 当前状态、交易状态、状态 |
| 交易号 | 交易单号、交易订单号、交易号、订单号 |
| 分类 | 分类 |
| 交易类型 | 交易类型 |

收支值须为支出/收入/转账/退款；交易类型包含退款时识别退款，充值/提现识别转账。失败、关闭、撤销、未支付记录跳过。`/`、`不计收支`等未明确的收支值列入错误，不擅自作为收入或支出。退款状态但无独立退款流水时不自动推断退款金额；需核对并补录，不能仅凭“已退款”把原消费改为退款。

存在交易号时，以“本人+来源+交易号+收支类型”去重；无交易号使用标准字段指纹。后者可能误判完全相同的两笔消费，预览应人工核对。相同订单多次部分退款可能需要手工拆分补录；不同平台间不会仅凭金额自动去重。银行卡与支付平台重复流水、家庭内部转账需人工核对。

分类优先使用有效内置分类，否则按商家/备注关键词匹配；未知归入待确认。当前不使用外部AI，不向第三方发送账单。修改分类不会自动生成新的商家规则。

`/import/confirm` POST：`token` 用户绑定的30分钟预览令牌；`shared=1` 可选，默认私有。有效记录可在有错误行时单独确认，未识别行不会入账；页面展示最多50条预览、100条错误。确认原子提交，重复确认不重复入账。过期预览在下次上传时清理。原文件不落盘，预览JSON暂存在数据库。

`/import/<batch_id>/undo` POST：限本人，删除该批真正新增的全部记录，含之后编辑的记录；不删除导入时被跳过的既有账单。操作前页面二次确认，之后可以重新上传原文件。界面展示最近30批。需要保留后续修改时先导出再撤销。

## 6. 统计、预算与提醒

- 支出：`expense金额 - refund金额`；允许净支出为负。退款计入退款发生月，分类需人工核对。
- 收入：仅 `income`；结余=收入-净支出；转账不计入三者。结余不是账户余额。
- 首页全家/家庭预算只计共享记录；个人视图含本人私有记录。家人视图只计同家庭他人共享记录。
- 环形图只绘制正净支出，负值在金额列表中保留；非正分类不参与面积占比。趋势图显示有交易日期，日期间距按整月天数比例；金额明细可展开查看。
- 月度比较：上月净支出大于0时计算环比；否则显示不可比。
- `/budgets` POST：`month`、`category`、`amount`；限管理员。0停用；同月同类覆盖。分类预算与总预算分别比较，不相加。80%/100%预警在页面打开时按当前数据派生显示，不主动重复推送。
- `/settings` POST：`reminder` HH:MM、`enabled=1` 开关、`categories` 中文逗号分隔，最多20类，每类12字。
- 每日提醒仅在北京时间到达设置时间后、访问首页时显示。没有后台定时任务、浏览器推送、邮件、微信订阅消息；网页关闭时不会通知。

## 7. 导出、备份与演示

- `/export` GET：`month`、`scope`；只导出有权访问的记录，CSV UTF-8 BOM。可能触发Excel公式的文本加单引号防护。此导出用于查阅，不承诺原样重导入（列无原交易号、共享字段不恢复）。
- `/example` GET：下载通用示例CSV。
- `python manage.py backup <新文件路径>`：当前 `DATA_DIR` 数据库一致性快照，拒绝覆盖；另行保存 `secret.key`。
- `start-demo.ps1`：设置 `DATA_DIR=项目/data/demo`、`PORT=8001`，只对空演示数据库创建虚构数据；账号 `demo`、`family`，密码均为 `demo-lizhi-2026`。
- `start.ps1`：使用当前环境配置；新开PowerShell以免继承演示脚本临时变量。默认正式数据 `data/ledger.sqlite3`、端口8000，无预设正式账号。
