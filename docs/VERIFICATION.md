## 用户本机试用顺序

1. 新开PowerShell，运行start-demo.ps1，打开8001端口登录演示账号。
2. 手机和电脑分别检查首页、账单、统计、预算、我的。
3. 在正式环境新建两个测试账号，使用邀请码加入同一家庭。
4. 导入examples中的CSV，确认默认私有；再逐笔共享，核对另一账号可见范围。
5. 上传同一文件确认重复跳过，撤销后重新上传，核对恢复入账。
6. 用自己的真实导出文件先预览，重点核对退款、转账、金额、时间及错误行。

功能适用范围以README和PARAMETERS为准；演示账本中的数字和成员均为虚构。
